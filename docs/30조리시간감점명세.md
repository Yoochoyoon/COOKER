# 30 조리 시간 감점 명세

한 판의 조리에 제한 시간을 두고, 시간을 넘기면 감점하는 기능의 구현 명세다. 담당은 [유초윤](#8-담당) 님이며, 타이머 화면도 유초윤 님이 맡는다.

> **미확정** 표시 항목은 팀에서 확정한 뒤 이 문서를 고친다.

## 1. 목적

- 조리에 마감 압박을 줘서 바쁜 느낌을 만든다.
- 시간을 넘겨도 바로 실패로 끝내지 않고, 맛 점수를 조금씩 깎는다.
- 방식마다 제한 시간을 다르게 둔다.

## 2. 제한 시간

| 방식 | 제한 시간 (제안) |
| --- | --- |
| 굽기 | 40초 |
| 볶기 | ~~35초~~ → 45초 (11/27 영은) |
| 끓이기 | 50초 |

**미확정:** 제한 시간 값. 실제 조리 흐름을 플레이테스트한 뒤 정한다.

### 11/27 점검 (영은, 계산)

가장 느린 재료가 알맞음(구간 시작)까지 걸리는 시간을 계산했다. 중불, 바늘을 잘 맞추면 구간 안 95%, 가만히 두면 72%로 잡았다 (docs/26 시뮬레이션). 볶기는 젓는 동안 0.7배, 끓이기는 거품 동안 1.2배를 넣었다.

| 방식 (제한) | 1주차 감자, 잘 맞춤 | 1주차 감자, 가만히 | 4주차 감자, 잘 맞춤 | 4주차 양파, 잘 맞춤 |
| --- | --- | --- | --- | --- |
| 굽기 (40초) | 20초 | 27초 | 18초 | 12초 |
| 볶기 (35초 → 45초) | **39초** | 52초 | 34초 | 23초 |
| 끓이기 (50초) | 38초 | 50초 | 34초 | 22초 |

- 볶기 35초는 1주차에 잘해도 감자가 익기 전에 감점이 시작돼서 45초로 올렸다. 가만히 두면(52초) 여전히 감점을 받는다.
- 굽기와 끓이기는 잘하면 제한 안, 가만히 두면 제한 근처라 그대로 둔다.
- 1초당 감점 0.5점, 상한 30점, 강제 종료 여유 25초는 그대로 둔다. 플레이테스트(11/29) 결과를 보고 다시 정한다.

- 제한 시간은 조리 시작부터 조리 완료 버튼을 누르기까지로 잰다.
- 간 고르기 시간(`docs/29`)은 포함하지 않는다.

## 3. 감점

| 항목 | 내용 |
| --- | --- |
| 감점 시작 | 제한 시간을 넘긴 순간부터 |
| 감점 방식 | 1초마다 전체 익힘 값의 맛 점수에서 일정량을 뺀다 |
| 감점 상한 | 맛 점수가 0을 넘게 깎이지 않는다 |
| 실패 여부 | 시간 초과만으로 실패(굶음)가 되지는 않는다 |

**미확정:** 1초당 감점량. 제안은 0.5점이다. 0~100 기준 점수에서 최대 약 30점까지 깎일 수 있다.

## 4. 타이머 표시

- 남은 시간을 조리 화면 위쪽에 표시한다. 기존 `cook_timer` 그림을 쓴다.
- 남은 시간이 10초 이하가 되면 숫자 색을 바꾼다.
- 제한 시간을 넘기면 숫자를 `+0:05`처럼 초과 시간으로 바꾼다.
- 표시 위치와 연출은 유초윤 님이 맡는다.

## 5. 코드 연결 (제안)

`Cook.cs`의 조리 시간 처리에 붙인다.

- **속성:** 방식별 제한 시간, 경과 시간, 초과 시간, 감점 누적값.
- **메서드:** 매 프레임 경과 시간 갱신, 초과 시 감점 누적, 감점 값을 맛 점수에 넘기기.

새 파일 `Cook.Time.cs`에 partial class로 두면 `Cook.cs`에는 호출만 남는다.

## 6. 수치 목록 (`BalanceData`)

- 방식별 제한 시간 (제안값은 2절)
- 1초당 감점량 (제안 0.5)
- 감점 상한 (제안 30)
- 10초 이하 강조 기준 (제안 10초)

수치를 정하면 바꾼 값과 이유를 `docs/09`에 한 줄씩 남긴다.

## 7. 결과 표시

- 결과 화면에 "시간을 넘겨 맛이 깎였어요"처럼 감점 이유를 한 줄 넣는다.
- 결과 화면 문구는 **미확정.** 넣을지 정한다.

## 8. 담당

- **유초윤:** `Cook.Time.cs`(새 파일), 제한 시간과 감점 계산, 타이머 화면, 강조와 초과 표시, `BalanceData` 수치, `docs/09` 기록.
- **영은:** 필요하면 타이머 그림 연결(요청으로 진행).

## 9. 테스트

- 방식마다 제한 시간에 맞춰 타이머가 흐르는지 확인한다.
- 제한 시간 전에 조리를 마치면 감점이 없는지 확인한다.
- 제한 시간을 넘긴 뒤 1초마다 감점이 누적되는지 확인한다.
- 감점 상한에서 더 깎이지 않는지 확인한다.
- 시간 초과만으로 실패(굶음)가 되지 않는지 확인한다.
- 10초 이하 강조와 초과 표시가 맞게 바뀌는지 확인한다.
- 간 고르기 시간이 감점에 포함되지 않는지 확인한다.
- 빌드 전에 인터넷을 끊고 한 판을 끝까지 돌린다.

## 10. 확정이 필요한 것

1. **제한 시간:** 방식별 값. 플레이테스트 후 조정할지.
2. **감점량:** 1초당 0.5점이 맞는지, 상한 30점이 맞는지.
3. **결과 화면 문구:** 감점 이유를 넣을지.
