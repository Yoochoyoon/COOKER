# 튜토리얼 문구 정리 (윤혁진)

목표: 도움말만 읽고 1주차 1일차를 끝낼 수 있게 한다 (docs/19 7번). 첫날 가이드 문구는 짧게 다듬는다.

## 지금 상태에서 찾은 문제

| 위치 | 지금 문구 | 문제 |
| --- | --- | --- |
| 하루 선택 첫날 쪽지 (`GameFlow.Core.cs:583`) | "엄마가 보낸 달걀! 첫날은 달걀을 굽는다. 불 세기와 꺼내기를 익혀 보자. 실패해도 굶지 않으니 다시 하면 돼!" | 다음에 눌러야 할 [조리 시작]이 없다. 세 줄이라 길다. |
| 조리 화면 첫날 가이드 (`GameFlow.Cook.cs:119`, 새 화면은 `:53`) | "[첫날 가이드] 재료를 팬에 넣고, 게이지가 주황일 때 꺼내! 너무 오래 두면 탄다." | 쪽지는 "불 세기"를 익히라고 하는데 여기에는 불 세기 설명이 없다. 말투(반말)가 다른 안내와 다르다. |
| 도움말 | 첫날 순서 설명 없음 | 도움말만으로 1일차를 끝낼 수 있는지 확인할 수 없었다. |

## 바꾼 것

- **내 파일 `Help.cs`**: 게임 규칙 탭 맨 위에 "첫날 따라 하기" 4줄을 넣었다 (장보기, 조리 시작, 팬에 넣고 불 세기와 꺼내기, 실패해도 다시).

## 파일 주인에게 보내는 요청

주인이 아닌 파일은 요청으로만 바꾼다 (CLAUDE.md).

**유초윤: `GameFlow.Core.cs` 583번째 줄 첫날 쪽지**
- 바꿀 값: "엄마가 보낸 달걀!\n[조리 시작]을 눌러 구워 보자.\n실패해도 굶지 않으니 다시 하면 돼!"
- 이유: 다음에 할 행동을 알려 주고, 세 줄 내용을 짧게 줄인다. 불 세기는 조리 화면 안내가 맡는다.

**영은: `GameFlow.Cook.cs` 첫날 가이드 문구 (119번째 줄, 새 화면 53번째 줄)**
- 바꿀 값: "[첫날 가이드] 불 세기는 1·2·3키. 게이지가 주황일 때 꺼내요. 너무 두면 타요."
- 이유: 쪽지에서 뺀 불 세기 설명을 여기서 한 번에 알려 주고, 말투를 "~해요"로 맞춘다.

## 확인 방법

- 도움말(게임 규칙 탭)만 읽고 1주차 1일차를 끝낼 수 있는지 지인에게 시켜 본다 (docs/11 플레이테스트).
- 4:3과 16:9에서 도움말 글이 잘리지 않는지 본다.
