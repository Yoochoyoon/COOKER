# 21. 요리 그림 목록 (Assets/Resources/AiDishes/)

게임은 요리를 완성하면 `Assets/Resources/AiDishes/` 안의 파일을 찾아 식사 화면과 도감에 보여 준다. 파일이 없으면 재료 색으로 그린 임시 그림이 나온다. 그림을 넣으면 코드를 고치지 않아도 바뀐다.

이름과 조합의 출처: 엑셀 `COOKER_도감_레시피_30종.xlsx`. 같은 조합이 두 개인 5곳은 대표 이름 하나만 남겼다 (돼지고기+양파 굽기는 "돼지고기양파구이", 돼지고기+양파 볶기는 "돼지고기제육볶음", 감자+양파 볶기는 "감자채볶음", 감자+양파 끓이기는 "감자국", 감자+돼지고기+양파 끓이기는 "돼지고기감자짜글이"). 튀기기 요리는 엑셀에 없어서 기존 이름을 그대로 쓴다.

## 규칙

- **파일 이름**: `cute2_<재료>-good_<재료>-good_<방식>.png`. 재료 id는 알파벳 순서로 정렬한다.
  - 재료 id: `egg`(달걀), `kimchi`(김치), `onion`(양파), `pork`(돼지고기), `potato`(감자), `shrimp`(새우), `tofu`(두부)
  - 방식: `Grill`(굽기), `Stirfry`(볶기), `Boil`(끓이기), `Fry`(튀기기)
- **익힘**: 항상 `good`(알맞음) 한 장만 만든다.
- **크기**: 1024×1024 PNG.
- **스타일**: 같은 화풍, 같은 각도(위에서 내려다본 접시), 밝은 배경 하나로 통일한다.
- **글자**: 그림 안에 글자를 넣지 않는다.
