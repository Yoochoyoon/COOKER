# 26 불 바늘 게이지 명세

조리 화면의 불 세기를 바늘로 보여 주고, 플레이어가 밸브로 바늘을 적정 구간에 머물게 하는 기능의 구현 명세다. 담당은 [영은](#9-담당), 판정 연결과 수치는 유초윤 님이 맡는다.

> **미확정** 표시 항목은 팀에서 확정한 뒤 이 문서를 고친다.

## 1. 목적

- 불 세기를 바늘로 보여 주고, 플레이어가 밸브로 바늘을 적정 구간에 두게 한다.
- 바늘이 구간을 벗어나면 화살표와 밸브 효과로 즉시 조작하도록 유도한다.
- 모든 요리(굽기, 볶기, 끓이기)에 같은 게이지를 쓴다.

## 2. 화면 구성

- **게이지:** 조리 화면 왼쪽에 세로로 둔다. 바늘이 움직이는 홈, 적정 구간 띠, 바늘로 이루어진다.
- **밸브:** 게이지 바로 아래에 둔다. 기존 손잡이를 그대로 쓴다.
- **화살표:** 바늘 옆에 둔다. 바늘이 가야 할 방향을 가리키며, 평소에는 숨긴다.
- **팬:** 가운데에 그대로 둔다.

## 3. 동작

| 항목 | 내용 |
| --- | --- |
| 바늘 움직임 | 자동으로 왕복한다. 중심값을 기준으로 진폭 안에서 움직인다. |
| 바늘 중심 | **미확정.** 밸브 위치를 중심으로 쓰는 것을 제안한다. 밸브를 올리면 중심이 올라가고, 바늘은 그 주변을 흔든다. |
| 적정 구간 | 방식마다 다르게 둔다. 값은 `BalanceData`에 둔다. |
| 구간 안 | 익힘이 정상 속도로 오른다. |
| 구간 밖 | 익힘 속도가 줄어든다. 줄이는 비율은 `BalanceData`에 둔다. |
| 화살표 방향 | 바늘이 구간 위에 있으면 아래 화살표, 아래에 있으면 위 화살표. |

## 4. 상태

| 상태 | 조건 | 표시 |
| --- | --- | --- |
| 정상 | 바늘이 구간 안에 있다 | 화살표 숨김, 게이지 기본 테두리 |
| 경고 | 구간 밖에 `T1`초 이상 계속 있다 | 화살표 표시, 화살표 깜빡임 |
| 위험 | 구간 밖에 `T2`초 이상 계속 있다 | 게이지 테두리 빨간색, 밸브 깜빡임 강화, 짧은 경고음 |

`T1`, `T2`는 **미확정**이다. 제안값은 `T1` 0.6초, `T2` 2.0초다.

## 5. 효과 수치

- **깜빡임:** 약 0.5초 주기로 투명도를 오르내린다. 화살표와 밸브 링에 적용한다.
- **게이지 테두리:** 경고 상태에서 2px 빨간색, 정상 상태에서 0.5px.
- **밸브 링:** 위험 상태에서 점선 링을 켠다.
- **경고음:** 위험 상태에 들어갈 때 한 번만 재생한다. `Sound.Play`를 쓴다.

## 6. 입력

- 밸브 조작은 기존 방식을 그대로 쓴다. 기존 `SetFire` 호출 경로를 유지한다.
- 새 키는 추가하지 않는다.

## 7. 코드 연결 (제안)

새 파일 `Cook.Fire.cs`에 둔다.

- **속성:** 바늘 위치(0~1), 구간 안 여부, 구간 밖 누적 시간, 화살표 방향(-1, 0, 1), 현재 상태.
- **메서드:** 밸브 값 설정, 매 프레임 갱신, 익힘에 곱할 보정값 반환.

`Cook.cs`의 `Tick`에서 보정값을 한 번 곱한다. `GameFlow.Cook.cs`는 게이지와 화살표 그리기, 밸브 효과만 맡는다.

## 8. 수치 목록 (`BalanceData`)

- 왕복 주기 (방식별)
- 진폭
- 적정 구간 시작과 끝 (방식별)
- `T1`, `T2`
- 구간 밖 익힘 보정 계수

수치를 정하면 바꾼 값과 이유를 `docs/09`에 한 줄씩 남긴다.

## 9. 담당

- **영은:** `Cook.Fire.cs`(새 파일), 게이지, 화살표, 밸브 효과, 경고음.
- **유초윤:** `Cook.cs`의 호출 한 줄, `BalanceData` 수치, `docs/09` 기록, 판정과 값 확인.

## 10. 테스트

- 바늘이 구간 밖으로 나갔을 때 화살표 방향이 맞는지 확인한다.
- `T1`, `T2`에서 상태가 바뀌는지 확인한다.
- 밸브를 돌려 바늘을 구간 안에 두면 경고가 꺼지는지 확인한다.
- 굽기, 볶기, 끓이기 모두에서 구간 값이 맞는지 확인한다.
- 조리 결과와 저장 파일(`run.json`, `dex.json`)에 영향이 없는지 확인한다.
- 빌드 전에 인터넷을 끊고 한 판을 끝까지 돌린다.

## 11. 확정이 필요한 것

1. **밸브와 바늘의 관계:** 밸브가 바늘의 중심을 옮기는 방식이 맞는지.
2. **적정 구간 값:** 방식별 구간을 지금 정할지, 제안값을 쓰고 나중에 조정할지.
3. **`T1`, `T2`:** 제안값(0.6초, 2.0초)을 쓸지.
