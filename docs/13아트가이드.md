## 개요
그림 파일을 정해진 이름으로 넣기만 하면 게임에 나온다. 코드를 고칠 필요 없다. 파일이 없으면 지금처럼 단색으로 대신 그려지므로, 한 재료씩 넣어도 게임은 깨지지 않는다.

## 넣는 곳과 파일 이름
`Assets/Resources/Art/` 폴더에 넣는다. (Resources 폴더 이름과 위치를 바꾸면 안 된다.)

| 재료 | id | 파일 3장 |
|---|---|---|
| 달걀 | `egg` | `egg_raw.png`, `egg_cooked.png`, `egg_burnt.png` |
| 두부 | `tofu` | `tofu_raw.png`, `tofu_cooked.png`, `tofu_burnt.png` |
| 양파 | `onion` | `onion_raw.png`, `onion_cooked.png`, `onion_burnt.png` |
| 감자 | `potato` | `potato_raw.png`, `potato_cooked.png`, `potato_burnt.png` |
| 돼지고기 | `pork` | `pork_raw.png`, `pork_cooked.png`, `pork_burnt.png` |
| 김치 | `kimchi` | `kimchi_raw.png`, `kimchi_cooked.png`, `kimchi_burnt.png` |

- `raw` = 날것, `cooked` = 알맞게 익은 상태, `burnt` = 탄 상태.
- **한 재료의 3장이 모두 있어야** 그림으로 나온다. 일부만 있으면 그 재료는 단색으로 나온다.

## 그림 규격
- 형식: PNG, 배경 투명.
- 크기: 정사각형 **512 x 512** 권장. 3장은 같은 크기와 같은 위치에 그려야 겹쳤을 때 어긋나지 않는다.
- 가운데에 재료를 크게 그린다. 화면에서는 팬 안에 큰 사각형 칸으로 보이고 가로세로 비율은 유지된다.
- 3장은 형태는 같게 하고 **색과 질감만** 바꾼다. (날것 → 익음 → 탄 것)

## 어떻게 보이나
조리 중에는 3장이 겹쳐 있고, 익힘에 따라 위의 두 장 투명도만 바뀐다.
1. 익힘 0~구간 시작: `raw` 위에 `cooked`가 점점 진해진다.
2. 알맞은 구간: `cooked`가 완전히 보인다.
3. 구간이 끝난 뒤: `cooked` 위에 `burnt`가 점점 진해진다.

그래서 **색 변화가 유일한 단서**라는 설계가 그대로 유지된다. 세 그림의 색 차이가 분명해야 플레이어가 꺼낼 때를 판단할 수 있다.

## 넣은 뒤 확인하는 방법
1. 파일을 `Assets/Resources/Art/`에 넣는다. Unity가 가져오게 잠시 기다린다.
2. 각 그림을 클릭해 Inspector에서 **Texture Type이 `Sprite (2D and UI)`** 인지 확인한다. (2D 프로젝트는 기본값이다. 아니면 바꾸고 Apply.)
3. Play를 눌러 해당 재료로 조리해 본다.
4. 안 나오면: 파일 이름 철자, 폴더 위치, 3장이 모두 있는지, Texture Type을 순서대로 확인한다.

## 지금은 지원하지 않는 것
다음은 아직 코드에 연결되지 않았다. 필요하면 알려 주면 추가한다.
- 팬, 배경, 버튼 그림 (지금은 단색)
- 장보기·식사·결산 화면의 재료 아이콘
- 완성 요리 그림, 엄마 전화 캐릭터
