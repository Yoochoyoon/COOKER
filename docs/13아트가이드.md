## 개요
그림 파일을 정해진 이름으로 넣기만 하면 게임에 나온다. 코드를 고칠 필요 없다. 파일이 없으면 지금처럼 단색으로 대신 그려지므로, 한 재료씩 넣어도 게임은 깨지지 않는다.

## 익힘 5단계
색이 서서히 변하지 않고, 단계가 바뀔 때 그림이 한 장씩 통째로 바뀐다. 단계 기준은 꺼내기 판정과 같다.

| 단계 | 파일 접미사 | 익힘 값 | 꺼내면 |
|---|---|---|---|
| 날것 | `raw` | 40 미만 | 실패(굶음) |
| 적게 익힘 | `under` | 40 ~ 적정 구간 시작 전 | 성공, 만족도 감소 |
| 알맞음 | `good` | 적정 구간 | 성공, 만족도 최대 |
| 많이 익힘 | `over` | 구간 끝 ~ 99 | 성공, 만족도 감소 |
| 탄 것 | `burnt` | 100 이상 | 실패(굶음) |

- 적정 구간은 방식마다 다르다. 굽기 60~75, 볶기 55~80, 끓이기 50~90 ([09](09재료와방식수치초안.md) 참고). 굽기는 구간이 좁아 `good` 그림이 짧게 보인다.
- 그림 단서가 유일한 판단 근거이므로, 다섯 그림의 차이가 분명해야 플레이어가 꺼낼 때를 알 수 있다. 특히 `under`/`good`/`over`가 구분되어야 한다.

## 넣는 곳과 파일 이름
`Assets/Resources/Art/` 폴더에 넣는다. (Resources 폴더 이름과 위치를 바꾸면 안 된다.) 재료당 5장, 6종이면 총 30장이다.

| 재료 | id | 파일 5장 |
|---|---|---|
| 달걀 | `egg` | `egg_raw`, `egg_under`, `egg_good`, `egg_over`, `egg_burnt` (.png) |
| 두부 | `tofu` | `tofu_raw`, `tofu_under`, `tofu_good`, `tofu_over`, `tofu_burnt` |
| 양파 | `onion` | `onion_raw`, `onion_under`, `onion_good`, `onion_over`, `onion_burnt` |
| 감자 | `potato` | `potato_raw`, `potato_under`, `potato_good`, `potato_over`, `potato_burnt` |
| 돼지고기 | `pork` | `pork_raw`, `pork_under`, `pork_good`, `pork_over`, `pork_burnt` |
| 김치 | `kimchi` | `kimchi_raw`, `kimchi_under`, `kimchi_good`, `kimchi_over`, `kimchi_burnt` |

- **한 재료의 5장이 모두 있어야** 그림으로 나온다. 일부만 있으면 그 재료는 단색으로 나온다.

## 조리 화면 구성
재료 그림은 조리 화면에서 아래 왼쪽 트레이(넣기 전), 가운데 팬(익는 중), 아래 오른쪽 접시(꺼낸 뒤)로 옮겨 다닌다. 같은 그림이 세 곳에 쓰이므로 작게 보여도 형태가 알아보이게 그린다. 트레이에서는 `raw` 그림이 보인다.

## 그림 규격
- 형식: PNG, 배경 투명.
- 크기: 정사각형 **512 x 512** 권장. 5장은 같은 크기와 같은 위치에 그려야 단계가 바뀔 때 흔들리지 않는다.
- 가운데에 재료를 크게 그린다. 화면에서는 팬 안에 큰 사각형 칸으로 보이고 가로세로 비율은 유지된다.
- 형태는 비슷하게 두고 색과 질감을 단계별로 바꾼다. (날것 → 덜 익음 → 알맞음 → 과함 → 탄 것)

## 단색일 때(그림이 없을 때)
같은 5단계를 `Data.cs`의 재료 색(`raw`, `cooked`, `burnt`)으로 나눠 보여 준다. 날것 = raw, 적게 익힘 = raw와 cooked의 중간, 알맞음 = cooked, 많이 익힘 = cooked와 burnt의 중간, 탄 것 = burnt.

## 넣은 뒤 확인하는 방법
1. 파일을 `Assets/Resources/Art/`에 넣는다. Unity가 가져오게 잠시 기다린다.
2. 각 그림을 클릭해 Inspector에서 **Texture Type이 `Sprite (2D and UI)`** 인지 확인한다. (2D 프로젝트는 기본값이다. 아니면 바꾸고 Apply.)
3. Play를 눌러 해당 재료로 조리해 본다. 약불로 하면 단계가 천천히 바뀌어 보기 쉽다.
4. 안 나오면: 파일 이름 철자, 폴더 위치, 5장이 모두 있는지, Texture Type을 순서대로 확인한다.

## 배경과 장바구니 (연결됨)
| 파일 (`Assets/Resources/Art/`) | 쓰이는 곳 | 규격 |
|---|---|---|
| `bg_title.png` | 타이틀 배경 | 16:9, 1920x1080. 글자·버튼은 그림에 넣지 않는다 |
| `title_logo.png`, `title_start.png`, `title_exit.png` | 타이틀 로고와 START·EXIT 글자 | 투명 PNG. 위치는 원본 타이틀 이미지(1671x941)를 따른다. 3장이 모두 있어야 나온다 |
| `bg_shop.png` | 장보기 배경 | 16:9. 재료 표와 장바구니는 그림에 넣지 않는다 |
| `shop_basket.png` | 장바구니 | 투명 PNG, 약 800x800. 재료가 위에서 날아와 담긴다 |

- 재료 아이콘은 장보기 줄과 장바구니 안에 `<id>_raw.png`(날것 그림)를 그대로 쓴다. 그림이 없으면 재료 색 사각형이 나온다.
- 요리 완성 그림은 AI가 만든다. 미리 만든 그림은 `Assets/Resources/AiDishes/`에 넣는다([docs/15](15AI요리그림비교시험계획.md)).

## 지금은 지원하지 않는 것
다음은 아직 코드에 연결되지 않았다. 필요하면 알려 주면 추가한다.
- 팬, 트레이, 접시, 버튼 그림 (지금은 단색)
- 하루 선택·조리·식사·결산 배경
- 엄마 전화 캐릭터
전체 목록과 제안 파일 이름은 노션 C 파트 페이지의 "이미지 소스 전체 목록"에 있다.

## 일정이 빠듯할 때
재료 6종을 한 번에 다 그리지 않아도 된다. 자주 쓰는 달걀, 돼지고기부터 5장씩 넣고 나머지는 단색으로 둔 채로 진행해도 된다.
