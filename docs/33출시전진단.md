- 문서: docs/01~32, 현업자 피드백 원문(docs/20).

**확인하지 못한 것 (추측이 섞인 부분은 표시)**

- 소리는 파일 목록과 문서만 봤고 들어 보지 않았다.
- 다른 PC에서 빌드 실행, 성능, 해상도별 화면은 확인하지 않았다.
- 튀기기 조리 화면과 끓이기·볶기의 최신 화면은 이번에 다시 띄우지 않았다(이전 확인 기준).

**사용자가 적어 준 내용과 다른 점**
- "Enter = 전체 재료 제거"는 실제로 **조리 완료**(팬의 재료를 모두 접시로 옮기고 판정)다. 결과는 같지만 플레이어에게는 "완료"로 안내한다.
- 음식 사진은 ChatGPT로 만들었다고 했는데, docs/32의 "이미지 생성 도구" 칸이 비어 있다. **이 정보로 채워야 한다.**

## 1. 프로젝트 현황

### 1-1. 콘셉트와 장르
- **자취 초보가 일주일치 장바구니로 7일을 버티는 코믹 생존 요리 게임.** 장르는 경영(예산·유통기한) + 실시간 조리 미니게임.
- Unity 6 2D URP, Windows, 마우스와 키보드. 학교 기말 제출용.

### 1-2. 진행 구조 (코드 기준)
```
타이틀 → 로비 → [장보기 → (하루 선택 → 조리 → 간 고르기 → 식사) × 7일 → 주 결산] 반복
```
- **장보기**: 예산 10,000원에서 시작, 최소 6개. 가격은 주마다 8% 오른다.
- **하루 선택**: 냉장고 재료 중 최대 2개(1주차)·3개(2주차부터)와 방식(굽기·볶기·끓이기, 칭호로 튀기기 해금)을 고른다. 엄마의 전언(추천 3개)을 볼 수 있다.
- **조리**: 40~50초 실시간. 재료를 넣는 순서, 불 세기 3단계(+불 바늘 게이지), 방식별 행동(뒤집기·젓기·뚜껑·기름 온도), 꺼내는 타이밍으로 만족도가 정해진다.
- **간 고르기**: 조리 후 소금·후추·간장 등 4지선다.
- **식사**: 요리 사진, 이름, 만족도, 반응 한 줄. 새 요리는 도감 등록.
- **주 결산**: 만족도 50% + 다양성 30% + 남은 재료 20%로 S/A/B/C 등급, 다음 주 예산(6,000~12,000원).

### 1-3. 승리와 패배
- **패배**: 그날 먹을 수 있는 요리가 없으면 굶는다. 주마다 비상 라면 1번은 넘어가고, 두 번째로 굶으면 끝난다. 결과는 "버틴 일수".
- **승리 조건은 없다.** 주가 끝없이 이어진다. 목표가 "오래 버티기"뿐이라 **언제 끝내야 할지, 무엇을 잘했는지가 흐릿하다** (아래 3장에서 다룸).

### 1-4. 구현된 시스템 (확인함)

### 1-5. 임시이거나 최종 리소스가 아닌 것
- **결산·굶음·도감·칭호·엄마의 전언·도움말**은 분홍 물방울 배경 + 기본 카드 UI다. 로비·타이틀·하루 선택·장보기는 새 그림으로 바뀌어서 **두 가지 화풍이 섞여 있다.**
- 효과음 14개와 배경 음악은 코드로 합성했다(docs/22). 저작권 걱정은 없지만 품질은 들어 보고 판단해야 한다.
- 타이틀 그림에 스파클 장식이 구워져 있어 버튼과 살짝 겹친다.
- 캐릭터는 로비의 앉은 포즈 한 장뿐이고, 식사·결산·굶음에서 캐릭터가 나오지 않는다.

## 3. 게임 플레이와 재미

### 3-1. 처음 하는 사람
- **좋은 점**: 첫날 달걀 가이드, 엄마 추천, 키 안내가 버튼 안에 있어 길을 잃을 일은 적다(코드 기준).
- **걱정되는 점 (추측)**: 조리 화면에 처음부터 불 바늘, 재료 순서, 방식별 행동, 시간 제한이 한꺼번에 나온다. 최근 이틀 동안 시스템이 여러 개 추가됐는데(불 바늘, 순서, 간, 시간 감점) **사람이 해 본 기록이 없다.** 처음 하는 사람이 "왜 점수가 깎였는지" 이해하는지 확인이 가장 급하다.

### 3-2. 여러 번 하는 사람
- **반복 구조**: 하루 = 재료 고르기 → 40~50초 조리 → 간 → 식사. 7일이 한 주.
- 다양성: 재료 7종 × 방식 4 × 1~3개 조합 = 252가지 요리와 사진, 칭호 8개, 도감. **수집할 거리는 충분하다.**
- **부족한 점**
  1. **목표가 "오래 버티기" 하나다.** 끝이 없고 최고 기록도 저장하지 않아 "이번 판은 잘했다"는 기준이 없다.
  2. **보상이 결과에 영향을 주지 않는다.** 칭호 8개 중 7개가 보상 "없음". 잘 만들어도 다음 주 예산이 조금 늘 뿐이다.
  3. **주가 지나도 새 규칙이 거의 없다.** 2주차에 재료 3개가 되는 것 외에는 가격만 오른다.
  4. 조리 미니게임은 방식마다 행동이 달라 손맛은 있다. 하지만 같은 방식을 여러 번 하면 차이가 재료의 익는 속도뿐이다.
- **10분 이상 할 만한가**: 한 주(7끼)가 약 10~12분으로 추정된다. **한 주는 충분히 버틸 만하고, 두 번째 주부터 반복이 느껴질 가능성이 높다** (추측, 플레이테스트로 확인 필요).
- **핵심 차별점**: "장바구니 → 유통기한 → 굶지 않기"라는 자취 생존 경영과, 방식별로 다른 손 조작 미니게임의 결합. 그리고 매 끼 결과가 실제 음식 사진과 이름으로 나오는 것.

## 4. 밸런스와 시스템

| 항목 | 판단 | 근거 |
| --- | --- | --- |
| 조작 직관성 | 보통 | 재료 넣기 Z~N, 꺼내기 Enter, 방식 행동 Space, 불 1·2·3, 간 Q~R. **키가 많다.** 단, 모두 마우스로도 된다 |
| 재료가 많을 때 | 문제없음 | 한도 3개라 키는 최대 3개만 쓴다 |
| 익힘 표시 | 좋음 | 재료 그림이 5단계로 바뀌고 게이지가 있음 |
| 실패 원인 이해 | **확인 필요** | 감점 요소가 5가지(순서, 불 바늘, 시간, 방식 행동, 간)다. 식사 화면은 만족도 숫자만 보여 주고 **무엇 때문에 깎였는지 나누어 보여 주지 않는다** |
| 난이도 상승 | 약함 | 1주차에 쉬움 보정(ease)이 있고 이후 가격 +8%/주뿐 |
| 실력 차이가 결과에 반영되나 | 그렇다 | 판정이 재료별 익힘·타이밍·행동에 따라 0.5~1.0배로 달라짐 |

- **유지할 것**: 익힘 5단계, 방식별 행동, 간 고르기, 재료 한도 3개.
- **고칠 것(제출 후)**: 식사 화면에 감점 내역 한 줄씩("뒤집기 놓침 −10", "시간 초과 −4"). 원인을 알면 다시 하고 싶어진다. 비용 S~M, 효과 큼.
- **바꿀 것(제출 후, 플레이테스트 결과에 따라)**: 첫 주에 켜지는 시스템 수 줄이기(3-3의 6번).
