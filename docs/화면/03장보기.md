# 03 장보기

한 주 동안 먹을 재료를 예산 안에서 산다. 로비에서 [게임 시작]을 누르면 온다.

## 버튼
| 버튼 | 동작 | 단축키 |
|---|---|---|
| 재료별 + | 그 재료를 1개 장바구니에 담는다 (남은 예산보다 비싸면 누를 수 없다) | 숫자 1~7 |
| 재료별 − | 담은 재료를 1개 뺀다 (담은 게 없으면 누를 수 없다) | Shift + 숫자 |
| 구매 확정 | 장바구니를 사서 재료를 보유한다 → 하루 선택으로 간다 | Enter |

- 담은 개수가 최소치에 못 미치면 구매 확정이 막히고 "최소 N개 필요"로 바뀐다.

## 정보 표시
| 항목 | 내용 |
|---|---|
| 주차 제목 | "N주차 장보기" |
| 남은 예산 | 예산 − 장바구니 합계 |
| 안내 문구 | 1주차 "6끼분 담기 · 첫날 달걀은 무료", 2주차부터 "7끼분 채우기 · 이월 재료 있음, 가격 인상" |
| 재료 표 | 재료마다: 번호·이름·**보유 개수**, 가격, 유통기한(일), 담은 수량 |
| 담은 재료 수 | 장바구니의 총 개수 |
| 장바구니 | 담은 재료 종류마다 그림이 하나씩 보인다 (최대 6종) |

- 재료 가격은 매주 8%씩 오른다. 전 주에서 남아 이월된 재료는 보유 개수에 보이고, 최소 개수가 그만큼 줄어든다.
- 유통기한이 지난 재료는 이 화면에 들어올 때 버려진다.
- 새우는 **"자취 생존자" 칭호를 얻기 전에는 상점에 나오지 않는다** (튀김 해금).

## 연출
- 재료를 담으면 줄에서 장바구니로 날아가 들어가고 장바구니가 통통 튄다. 빼면 반대로 돌아온다.

## 쓰는 이미지
| 파일 | 내용 |
|---|---|
| `bg_shop.png` | 배경 |
| `<재료>_shop.png` | 재료 아이콘 (예: `egg_shop.png`). 표·장바구니·조리 대기열에서 쓴다 |
| `shop_basket_back.png`, `shop_basket_front.png` | 장바구니 뒷면·앞면 (재료가 그 사이에 끼인다) |

- 장바구니 그림이 없으면 빨간 상자, 재료 아이콘이 없으면 재료 색 사각형으로 대신한다.
