# 04 하루선택

오늘 먹을 요리의 **재료와 조리 방식을 고른다.** 장보기가 끝난 뒤, 그리고 식사가 끝날 때마다 온다. 한 주 7일 동안 하루에 한 번씩 이 화면을 거친다.

## 입력과 버튼
| 항목 | 동작 | 단축키 |
|---|---|---|
| 식탁 위 재료 | 도마로 **끌어다 놓거나 클릭**하면 이번 요리 재료로 고른다 (여러 개 가능) | 숫자 1~ |
| 도마 위 재료 | 식탁으로 끌어 빼거나 클릭하면 뺀다 | |
| 조리 방식 버튼 (굽기·볶기·끓이기, 해금 후 튀기기) | 조리 방식을 고른다. 고른 방식은 색이 다르게 보인다 | Q W E R |
| 엄마의 전언 | 엄마의 전언 팝업을 연다 (첫날 가이드에서는 없다) | M |
| 도감 | 도감 팝업을 연다 | D |
| 조리 시작 | 조리 화면으로 간다 (재료 1개 이상 + 방식을 골라야 켜진다) | Enter |

## 정보 표시
| 항목 | 내용 |
|---|---|
| 일차 | "N주차 N일차 / 7일" |
| 비상 라면 | 남은 횟수 (주 1회), 이번 주에 먹은 끼니 수 |
| 식탁의 재료 카드 | 재료 그림, 이름, 보유 개수, 유통기한 (임박하면 "오늘까지!" 또는 "D-N", 카드가 붉어진다) |
| 도마 | 고른 재료. 비어 있으면 "재료를 여기로 끌어다 놓기" 안내 |
| 엄마의 전화 | 고른 재료에 대한 엄마의 한마디. 아무것도 안 골랐으면 안부 문구 |
| 선택 요약 | "재료 + 재료 / 방식" |

- 식탁은 보유 재료를 유통기한이 급한 것부터 보여 준다.
- 튀기기는 **"자취 생존자" 칭호를 얻기 전에는 방식 선택지에 나오지 않는다.**

## 첫날 가이드 (1주차 1일차)
- 재료는 엄마가 보낸 **달걀 + 굽기**로 고정되고, 방식 버튼을 누를 수 없다. 엄마의 전언도 없다.
- 안내 쪽지: "엄마가 보낸 달걀! 첫날은 달걀을 굽는다…". 실패해도 굶지 않고 다시 할 수 있다.
- 이 달걀은 재료값이 들지 않는다.

## 특수한 경우
- 보유 재료가 하나도 없으면(첫날 제외) 이 화면 대신 비상 라면 식사로 넘어간다.
