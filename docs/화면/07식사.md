# 07 식사

조리가 성공하면 그날의 요리를 먹는 화면. 요리 이름, 사진, 만족도를 보여 주고 도감에 등록한다.

## 버튼
| 버튼 | 동작 | 단축키 |
|---|---|---|
| 다음 날 | 다음 날 하루 선택으로 간다 | Enter |
| 결산 보기 | 7일째라면 이 이름으로 바뀌고, 주 결산 화면으로 간다 | Enter |

## 정보 표시
| 항목 | 내용 |
|---|---|
| 제목 | "N주차 N일차 식사" |
| 요리 사진 | 먼저 대체 그림이 나오고, AI가 그린 그림이 도착하면 바뀐다. 그리는 동안 진행 막대와 "로딩중... N%"가 보인다 |
| 요리 이름 | 먼저 아는 요리 이름으로 보이고, AI가 지은 이름이 오면 바뀐다 |
| "도감에 새로 등록!" | 처음 만든 요리일 때만 |
| 만족도 | 숫자 |
| 반응 한마디 | 만족도 80 이상 "엄청 맛있다! 자취 만세!", 60 이상 "나쁘지 않은데?", 40 이상 "먹을 만은 하다...", 그 아래 "일단 배는 채웠다." |
| 안내 | 일부 재료를 망쳐 버렸으면 "○○은(는) 망쳐서 버렸다..." |

## 비상 라면일 때
- 요리 사진 없이 이름 "비상 라면"과 만족도(20), 사유 문구만 나온다. 도감에는 올라가지 않는다.

## 참고
- 같은 요리를 다시 만들어 만족도가 더 높으면 도감 기록이 갱신된다.
- AI 그림은 도감에 들어가는 성공한 요리만 만든다. (Windows 빌드에서는 유료 AI, 에디터에서는 무료 서비스)
