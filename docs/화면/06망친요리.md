# 06 망친요리

조리가 끝났는데 **성공한 재료가 하나도 없을 때** 보이는 화면. 날것이거나 새까맣게 탄 재료의 모습을 그대로 보여 준다.

## 버튼
| 버튼 | 동작 | 단축키 |
|---|---|---|
| 계속 | 비상 라면(또는 굶음 판정)으로 넘어간다 | Enter |
| 다시 하기 | **첫날 가이드일 때만.** 하루 선택으로 돌아가 다시 조리한다 | Enter |

## 정보 표시
| 항목 | 내용 |
|---|---|
| 망친 재료 그림 | 탄/날것 상태 그대로의 재료를 접시 사진처럼 보여 준다 |
| 제목 | "새까맣게 탄(또는 날것 그대로인) 튀긴 감자" 식으로, 상태 + 방식 + 재료 이름 |
| 안내 문구 | 평소: "요리가 …이 되어 못 먹었다..." / 첫날: 엄마가 "첫날은 봐줄게. 다시 해 봐." |

- **망친 요리는 AI 그림을 만들지 않는다.** 재료를 그 익힘 색으로 칠한 대체 그림만 보인다.
- 평소에는 재료가 소모되고, 비상 라면을 먹게 된다. 첫날은 재료가 소모되지 않는다.

## 쓰는 이미지
- 재료의 익힘 단계 그림(`<재료>_raw.png`, `_burnt.png` 등)을 사진 틀 안에 보여 준다. 없으면 재료 색으로 칠한 그림.
