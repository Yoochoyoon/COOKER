# 화면 목록과 흐름

각 화면에 어떤 기능이 있고, 무엇이 버튼이며 무엇이 정보 표시인지 정리한 문서 묶음이다. **버튼의 위치·크기는 적지 않는다** (디자인 단계에서 바뀐다). 이미지 파일이 쓰이는 곳은 파일 이름만 적는다.

용어
- **버튼**: 누르면 동작이 일어나는 것
- **정보 표시**: 보기만 하는 것 (글자·숫자·그림)
- **입력**: 끌어다 놓기·키보드·슬라이드 같은 조작
- 단축키는 `[ ]` 안에 적는다.

## 화면 흐름
```
타이틀 ─┬→ 도감 / 칭호 목록 (팝업)
        └→ 로비 ─┬→ 도감 / 칭호 목록 / 냉장고 (팝업)
                 └→ 장보기 → [ 하루 선택 → 조리 → (망친 요리) → 식사 ] ×7일 → 주 결산 → 로비 (칭호 획득 팝업)
                                                                              ↘ 굶음(실패) → 타이틀
```
- 7일 동안 하루는 "하루 선택 → 조리 → 식사"가 한 바퀴다.
- 재료가 없거나 요리를 못 만들면 **비상 라면**(주 1회)으로 넘어가고, 두 번째부터는 굶음(실패)이다.

## 공통
- **그림 파일**은 `Assets/Resources/Art/`에 있고, 없으면 단색 도형으로 대신 그려진다. 이름 규칙은 [13 아트 가이드](../13아트가이드.md).
- **마우스와 키보드** 모두 되도록 만들었다. 화면마다 Enter/Space가 "가장 중요한 버튼"과 같다.
- 팝업은 Esc나 닫기 버튼으로 닫는다.
- **주요 버튼**(게임 시작·조리 시작·구매 확정·다음 날·다음 주·다시 하기·계속·확인·이걸로 할래)은 모두 같은 그림(`lobby_start.png`, 글자 없는 버튼)을 쓰고 글자는 코드로 올린다. 글자 모양은 흰 글자 + 갈색 주황 테두리다. 못 누르는 상태는 그림이 연해진다.
- **로비 버튼**: 판 도중(장보기·하루 선택·조리·식사)에는 로비로 갈 수 있는 버튼이 보인다 (주 결산 화면과 팝업이 열려 있을 때는 숨는다). 누르면 바로 가지 않고 확인 창이 뜬다: **이번 주차 진행이 취소**되고 1일 차부터 다시 시작하며, 지금까지 쓴 돈과 재료는 되돌려 받지 못한다. 조리 중에 누르면 **조리 중인 재료도 복구되지 않는다** (확인 창이 떠 있는 동안 조리는 멈춘다). 첫날 가이드의 달걀은 공짜라 잃지 않는다.
- **해금 전 내용은 보이지 않는다**: 새우·튀기기와 "튀김 명인" 칭호, 자취 생존자의 보상 내용은 해금되기 전에 숨겨진다.
