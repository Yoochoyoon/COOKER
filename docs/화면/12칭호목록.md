# 12 칭호 목록 (팝업)

모든 칭호와 달성 조건·진행도를 보고, **대표 칭호를 고르는** 창. 타이틀·로비·주 결산에서 열 수 있다 (단축키 T).

## 버튼
| 버튼 | 동작 |
|---|---|
| 닫기 | 팝업을 닫는다 (Esc) |
| 칭호 줄의 [대표로] | 그 칭호를 대표로 장착한다 (이미 대표면 [해제]로 바뀌고, 누르면 해제) |
| 칭호 줄의 [잠김] | 아직 얻지 못한 칭호. 누를 수 없다 |

- 대표 칭호는 **하나만** 고른다. 대표 칭호는 로비의 캐릭터 머리 위와 주 결산에 보인다.
- 대표 칭호는 **타이틀·로비·주 결산 화면에서만** 바꿀 수 있다. 다른 곳에서는 버튼이 꺼지고 안내 문구가 나온다.

## 정보 표시
| 항목 | 내용 |
|---|---|
| 제목 | "칭호 (얻은 수 / 전체 수)" |
| 대표 칭호 | 지금 장착한 칭호 (없으면 "대표 칭호가 없다") |
| 칭호 줄 | 이름, **달성 조건**, 달성 여부("달성!") 또는 **진행도**, **보상** |
| 보상 | 얻은 칭호의 보상은 강조색 (예: 튀김 해금) |

## 칭호 종류
| 칭호 | 조건 | 보상 |
|---|---|---|
| 집밥 입문 | 도감 5종 | 없음 |
| 자취 생존자 | 도감 10종 | **튀김 해금** (새우 + 튀기기) |
| 동네 밥집 사장 | 도감 20종 | 없음 |
| 한식 달인 | 도감 35종 | 없음 |
| 굽기 장인 | 굽기 요리 5종 | 없음 |
| 볶기 장인 | 볶기 요리 5종 | 없음 |
| 끓이기 장인 | 끓이기 요리 5종 | 없음 |
| 튀김 명인 | 튀김 요리 3종 | 없음 |

- 수치는 초안이며 플레이해 보고 조정한다 ([17](../17확정사항_로비칭호튀김.md)).
- 칭호 판정은 **주 결산 때와 굶어서 끝날 때** 한다. 얻은 칭호는 파일로 저장돼 다음 판에도 남는다.
