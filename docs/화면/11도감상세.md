# 11 도감 상세 (팝업)

도감에서 만든 요리 카드를 누르면 뜨는 설명 창. 그 요리의 이름·재료·**실제 레시피**·최고 만족도를 보여 준다.

## 버튼
| 버튼 | 동작 | 단축키 |
|---|---|---|
| 닫기 | 상세를 닫고 도감으로 돌아간다 | Esc / Enter / Space / D |
| 창 바깥 | 눌러도 닫힌다 | |

## 정보 표시
| 항목 | 내용 |
|---|---|
| 요리 사진 | AI 그림. 그리는 동안 대체 그림과 "AI가 그림을 그리는 중..." 문구 |
| 요리 이름 | AI가 지은 이름. 늦게 도착하면 열려 있는 창에서 바로 바뀐다 |
| 재료와 방식 | 재료 이름(처음 만들었을 때의 익힘 정도 포함) · 방식 |
| 레시피 | 번호가 매겨진 **실제 조리 순서**: 재료 손질 → 조리(불 세기·시간·넣는 순서) → 간 → 담기 |
| 최고 만족도 | 숫자와 별 |
| 메모 | 재료를 망쳐서 버린 적이 있으면 그 문구 |

## 레시피에 대해
- 게임 요령(뒤집기·젓기 등)이 아니라 **현실에서 이 요리를 만드는 방법**이다. 게임 요령은 엄마의 전언·조리 중 말풍선이 맡는다.
- 재료와 방식 조합에 맞춰 문장을 이어 붙여 만든다. 오래 걸리는 재료를 먼저 넣으라는 안내, 김치를 먼저 볶는 단계, 달걀물을 마지막에 붓는 단계 등이 조합에 따라 붙는다.
