# 13 칭호 획득 (팝업)

주 결산(또는 굶음)에서 **새 칭호를 얻은 뒤, 로비에 들어올 때** 가장 먼저 뜨는 알림 창.

## 버튼
| 버튼 | 동작 | 단축키 |
|---|---|---|
| 확인 | 팝업을 닫고 일반 로비로 간다 | Enter |

## 정보 표시
| 항목 | 내용 |
|---|---|
| 제목 | "칭호 획득!" |
| 얻은 칭호 | 새로 얻은 칭호 이름들 (여러 개면 한 줄에 같이) |
| 해금 안내 | **"자취 생존자"를 얻었을 때만**: "튀김 해금! 다음 장보기부터 새우가 나오고 튀기기를 고를 수 있다." |

## 동작
- 새로 얻은 칭호가 없으면 이 팝업은 뜨지 않는다.
- 처음 얻은 칭호는 자동으로 대표 칭호가 된다 (대표가 없을 때).
- 지금은 글자만 있는 단순한 창이다. 연출(효과·소리)은 디자인 단계에서 정한다.
