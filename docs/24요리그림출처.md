## 개요
`Assets/Resources/AiDishes/`에 있는 요리 사진의 출처와 가공 기록이다. 파일 이름 목록은 [21 요리 그림 목록](21요리그림목록.md)을 본다. 보고서의 AI 사용 기록을 쓸 때 이 문서를 근거로 한다.

> **아직 채우지 않은 칸**은 `[확인 필요]`로 적어 두었다. 생성 도구, 프롬프트, 날짜는 그림을 만든 사람이 채운다.

## 1. 시트별 출처
요리 사진은 시트 그림을 잘라서 만들었다. 시트 그림은 아래 표의 `생성 도구`로 만들었다.

| 시트 | 장수 | 커밋 | 생성 도구 | 생성 날짜 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 6번 시트 | 23장 | `a40c324` | [확인 필요] | [확인 필요] | 일부는 8번 시트 그림으로 덮어씀 |
| 8번 시트 | 24장 | `7ae9e6b` | [확인 필요] | [확인 필요] | 현재 파일의 기준 |
| 계란프라이 | 1장 | `2eaa4b3` | 원본 그림 (재료 그림 `계란3.png`) | [확인 필요] | 시트를 쓰지 않음, 확대 |

- 같은 파일이 두 시트에 모두 있으면 **마지막으로 커밋된 시트**가 현재 파일이다.
- `cute2_egg-good_Grill.png`(계란프라이)는 시트 그림이 아니라 원본 재료 그림에서 만들었다. 가져온 원본 위치는 [확인 필요].

## 2. 잘라 내고 다듬은 방법
시트 그림을 게임용 파일로 바꾼 과정이다. 같은 방법으로 다른 시트도 처리한다.

1. 시트를 격자(6열 x 5행)로 나눈다.
2. 배경의 흰색과 회색 체크무늬를 흰색 한 가지로 바꾼다. 시트에 체크무늬가 그림으로 들어 있어서 필요했다.
3. 흰색이 아닌 픽셀을 덩어리(연결된 영역)로 묶는다.
4. 각 칸의 가운데에 있는 가장 큰 덩어리만 남긴다. 옆 칸 요리의 일부가 들어오지 않게 하려는 것이다.
5. 그 덩어리의 가장자리에 여백을 더해 정사각형으로 맞춘다.
6. 1024 x 1024로 줄이고 PNG로 저장한다.

도구: Python 3.13과 Pillow. 작업 스크립트는 저장소에 넣지 않았다.

## 3. 알려진 문제
- **김치달걀전**: 6번, 8번 시트 어디에도 그림이 없어서 파일이 없다. 게임에서는 대체 그림이 나온다.
- **계란프라이**: 원본 재료 그림이 작아서 확대했다. 다른 요리보다 흐릿할 수 있다.
- **이름 대응 확인 필요**: `egg-good_onion-good_Grill`(양파 계란 전), `onion-good_Stirfry`(떡볶이 계열)는 시트에서 어떤 요리인지 눈으로만 맞췄다. 게임 식사 화면에서 확인하지 않았다.

## 4. 보고서 AI 사용 기록에 넣을 문장 (초안)
> 요리 사진은 [생성 도구]로 시트 그림을 만든 뒤, 직접 잘라서 게임 파일 규격(1024 x 1024, 투명하지 않은 흰 배경)에 맞췄다. 게임 실행 중에는 AI를 호출하지 않는다.

[생성 도구]와 "직접 그린 것인지 AI로 만든 것인지"는 확인 후 고친다.
