# 22. 소리 목록과 출처

## 출처와 라이선스

- 효과음 10개는 **외부 파일을 받지 않고 코드로 직접 합성했다** (사인파, 톱니파, 노이즈 조합). 저작권 문제가 없고, 팀이 자유롭게 고쳐 쓸 수 있다.
- 만든 스크립트: `docs/sfx_gen.py` (Python 표준 라이브러리만 사용)
- 다시 만들기: `py docs/sfx_gen.py Assets/Resources/Sfx` (같은 결과가 나오도록 난수 시드를 고정해 두었다)
- 생성일: 2026-11-21
- 소리를 외부에서 받은 파일로 바꾸면, 이 표에 출처 URL과 라이선스(CC0 등)를 꼭 적는다.

## 효과음 (`Assets/Resources/Sfx/`)

| 파일 | 이벤트 | 소리 | 길이 |
| --- | --- | --- | --- |
| `put.wav` | 재료 넣기 | 팬에 툭 + 짧은 지글 | 0.28초 |
| `take.wav` | 재료 꺼내기 | 위로 올라가는 뽁 | 0.14초 |
| `flip.wav` | 뒤집기 | 휙 + 착 | 0.36초 |
| `stir.wav` | 젓기 (연타) | 짧게 슥 | 0.09초 |
| `lid.wav` | 뚜껑 누르기 | 금속 쨍 | 0.5초 |
| `boil_over.wav` | 거품 넘침 | 보글보글 | 0.9초 |
| `success.wav` | 조리 성공 | 도-미-솔-도 띠링 | 0.75초 |
| `fail.wav` | 조리 실패 | 뿌우웅 내려가는 코믹한 소리 | 0.8초 |
| `click.wav` | 버튼 클릭 | 짧은 톡 | 0.05초 |
| `pop.wav` | 화면 번쩍임 (재료 망침, 뒤집기 놓침, 모두 실패) | 펑 | 0.55초 |

- `click.wav`는 파일만 있다. `UIKit.Btn`에 연결은 유초윤에게 요청한다.
- 재생 코드는 `Sound.cs`, 연결 위치는 `GameFlow.Cook.cs`의 `PlayCookSfx`.

## 배경 음악 (`Assets/Resources/Sfx/`)

- 효과음과 같은 방식으로 **코드로 합성했다**: `docs/bgm_gen.py` (다시 만들기: `py docs/bgm_gen.py Assets/Resources/Sfx`)
- 생성일: 2026-11-21
- 끝과 처음이 이어지는 루프 곡이다.
- 규칙은 `.ogg`지만 이 PC에 ogg 인코더가 없어 `.wav`로 넣었다. Unity가 가져올 때 압축하고, 코드는 확장자 없이 이름으로 찾으므로 나중에 `.ogg`로 바꿔도 코드는 그대로 둔다.

| 파일 | 화면 | 분위기 | 길이 |
| --- | --- | --- | --- |
| `bgm_title.wav` | 타이틀 | 통통 튀는 C장조, 110bpm | 약 17초 루프 |
| `bgm_lobby.wav` | 로비, 장보기, 하루 선택, 식사, 결산 | 느긋한 F장조, 88bpm | 약 22초 루프 |
| `bgm_cook.wav` | 조리 | 바쁜 G단조, 136bpm | 약 14초 루프 |

- 트는 곳: 게임 시작 시 `Sound.Boot`(타이틀), `Lobby.Show`(로비), `StartCook`(조리), `FinishCook`(조리가 끝나면 로비 곡으로)
- 한계: 한 판이 끝나 타이틀로 돌아가면 로비 곡이 계속 나온다. `GameFlow.Core.cs`의 `ShowTitle`에 `Sound.Music("bgm_title");` 한 줄이 필요하다 (유초윤에게 요청).
- `M` 키 음소거는 넣지 않았다. `M`은 이미 "엄마의 전언" 키라서 겹친다. 음량은 설정 화면(`Settings.cs`)에서 `Sound.MusicVolume`, `Sound.SfxVolume`으로 조절한다.
