# 23. 영은 파트: 조리, 로비, 소리 (보고서 초안)

기말 보고서의 "구현" 장에 들어갈 영은 담당 부분 초안이다. 담당 파일은 `GameFlow.Cook.cs`, `Lobby.cs`, `FireFlame.cs`, `Sound.cs`.

## 1. 조리 화면 (`GameFlow.Cook.cs`)

### 화면 구성
- 조리대 그림(`bg_cook`) 위에 방식별 조리도구(`cook_pan`, `cook_wok`, `cook_pot`)를 올린다. 그림이 없으면 단색 칸으로 대신 그려서 게임이 멈추지 않는다.
- 왼쪽 도마(대기 재료), 가운데 그릇(익는 중), 오른쪽 접시(다 된 재료) 세 자리로 재료가 움직인다.
- 가운데 위 **안내 한 줄**이 지금 해야 할 한 가지만 알려 준다. 급한 정도를 바탕색으로 나눈다: 빨강(거품 넘침 등 위급), 주황(뒤집기, 꺼낼 때), 연한 바탕(평소).
- 오른쪽 위 엄마 말풍선은 재료별 한마디와 방식별 요령을 4초마다 바꿔 보여 준다. 정답은 말하지 않는다.
- 재료 위 익힘 게이지(하양 → 노랑 → 주황 → 빨강)와 5단계 그림 변화가 판단 단서다.

### 조작
- 불 세기: 가스 밸브 손잡이를 돌리거나 숫자키 1·2·3.
- 넣기·꺼내기: 클릭, 끌어다 놓기, Z X C V B N.
- 방식별 고유 동작: 굽기는 뒤집기(Space), 볶기는 젓기 연타(Space·클릭), 끓이기는 뚜껑 누르고 있기(Space·마우스).

### 피드백 연출 (docs/19 4번)
| 상황 | 화면 | 소리 |
| --- | --- | --- |
| 재료를 알맞게 꺼냄 | 그릇에서 접시까지 포물선으로 날아가며 공중에서 살짝 커진다 (0.4초) | `take` |
| 재료를 망침 (날것, 탄 것) | 화면이 빨갛게 번쩍이고, 재료가 접시에서 부르르 떤다 | `take`, `pop` |
| 뒤집기 성공 | 화면이 하얗게 번쩍, 뒤집개가 팬 위로 들어와 뒤집는다 | `flip` |
| 뒤집기 놓침 | 화면이 주황으로 번쩍, 버튼 글자 "뒤집기 놓침" | `pop` |
| 조리 끝 (성공) | 0.5초 동안 마지막 재료가 접시에 닿는 걸 보여 주고 식사 화면으로 | `success` |
| 조리 끝 (모두 실패) | 화면 전체가 빨갛게 번쩍 | `fail`, `pop` |

- 번쩍임은 "번쩍 → 잠깐 어두움 → 번쩍 → 서서히 사라짐" 순서로 두 번 깜빡인다. 첫 순간은 하얗게 달아오른 색에서 원래 색(빨강, 주황)으로 바뀌어 빛이 터지는 느낌을 준다.

- 설계 근거: 성공과 실패가 **소리와 화면에서 동시에** 구분되어야 한다(docs/19 완료 기준). 색만으로 구분하지 않도록 움직임(날아감 대 떨림)도 다르게 했다.
- 조리가 끝나자마자 화면을 바꾸면 재료가 하나뿐일 때 날아가는 연출이 한 번도 보이지 않는다. 그래서 끝난 뒤 0.5초를 기다린다.

## 2. 로비 (`Lobby.cs`, `FireFlame.cs`)

- 한 판의 거점 화면. 타이틀 다음과 매 주 결산 뒤에 돌아온다.
- 디자인 시안 위치 그대로 그림 조각을 올린다: 배경, 냉장고(재료 보관함), 캐릭터(칭호), 책상, 칭호 표시, 주차·금액, 도감·게임 시작.
- 창 비율이 16:9가 아니어도 시안과 같게 보이도록 16:9 영역 안에 그린다.
- 불꽃(`FireFlame.cs`): 불 세기에 따라 조리도구 둘레 불꽃 길이와 색이 바뀐다.

## 3. 소리 (`Sound.cs`)

- `Sound.Play("이름")`: `Assets/Resources/Sfx/`에서 이름으로 찾아 재생한다. **파일이 없으면 조용히 넘어간다** (그림이 없으면 단색으로 그리는 `Art.Load`와 같은 원칙).
- `Sound.Music("이름")`: 배경 음악을 루프로 튼다. 같은 곡이면 다시 틀지 않는다.
- 효과음 10개, 배경 음악 3곡. 목록과 출처는 `docs/22소리목록.md`.
- 설계 근거:
  - 넣기·꺼내기·뒤집기는 클릭, 끌어다 놓기, 키보드 세 곳에서 일어난다. 부르는 곳마다 소리를 붙이면 빠뜨리기 쉽고, 키 처리는 다른 팀원 파일(`GameFlow.Core.cs`)에 있다. 그래서 **매 프레임 조리 상태가 바뀐 순간을 보고 한 곳(`PlayCookSfx`)에서 튼다.**
  - 시간이 다 되어 재료를 한꺼번에 꺼내면 같은 소리가 겹친다. 한 프레임에 한 번만 튼다.
  - 젓기는 연타라 소리가 겹쳐 웅웅거린다. 같은 소리는 0.12초 안에 다시 틀지 않는다.
  - 소리는 외부 음원 없이 코드로 합성했다(`docs/sfx_gen.py`, `docs/bgm_gen.py`). 라이선스 문제가 없고 시연 때 인터넷이 필요 없다.

## 4. 한계와 개선 방향

- 타이틀로 돌아올 때 타이틀 곡으로 바뀌지 않는다 (`GameFlow.Core.cs` 수정 요청 중).
- 버튼 클릭 소리 파일은 있지만 `UIKit.Btn`에 아직 연결되지 않았다 (`UIKit.cs` 수정 요청 중).
- `M` 키 음소거는 "엄마의 전언" 키와 겹쳐 넣지 않았다. 음량은 설정 화면에서 조절한다.
- 합성한 소리라 실제 녹음보다 단순하다. 시간이 있으면 CC0 녹음 소리로 바꿀 수 있다 (출처를 docs/22에 기록).

## 5. AI 사용 기록

- `Sound.cs`, 조리 효과음·연출 코드, 소리 합성 스크립트(`docs/sfx_gen.py`, `docs/bgm_gen.py`)는 AI 코딩 도구(Claude Code)의 도움을 받아 작성했다.
- 게임 실행 중에는 AI를 쓰지 않는다. 소리는 미리 만든 파일만 읽는다.
