## 개요
화면마다 **반드시 있어야 하는 기능(버튼)과 정보, 그림**을 적은 목록이다. 이 문서는 시안을 이미지 AI에 맡기기 위한 입력이다.

- 배치, 위치, 크기, 모양, 색, 분위기는 적지 않는다. 시안을 받을 때 자유롭게 정한다.
- 버튼 글자는 현재 게임에 적힌 문구다. 키 안내(`[Enter]` 등)는 기능의 일부라서 적었다.
- 그림 이름은 `Assets/Resources/Art/`의 파일 이름이다. 그림이 없으면 게임은 단색으로 대신 그린다.
- 기준: 2026-11-24 코드. 바뀌면 이 문서도 고친다.

## 0. 모든 화면에 공통
| 요소 | 기능 | 키 | 그림 |
| --- | --- | --- | --- |
| 설정 버튼 | 설정 창을 연다. 열면 게임이 멈춘다 | 없음 | 없음 (글자) |
| 도움말 버튼 | F1 도움말 화면을 연다 | F1 | 없음 (글자) |
| 로비 버튼 | 판 도중에 로비로 간다. 확인 창을 거친다 | 없음 | `icon_home` |
| 타이틀 버튼 | 로비에서 타이틀로 간다 | 없음 | 없음 (글자) |

- 로비 버튼은 장보기·하루 선택·조리·식사 화면에서만 보인다.
- 타이틀 버튼은 로비에서만 보인다.
- 버튼 바탕 그림은 `btn_base`다. 나인패치로 늘어난다.

## 1. 타이틀
**목적**: 게임 시작과 종료, 이어하기.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 시작 | 새 판을 시작하고 로비로 간다 | Enter |
| 종료 | 게임을 끈다 | 없음 |
| 이어하기 | 저장된 주의 로비에서 다시 시작한다 (저장이 있을 때만) | 없음 |
| 설정 | 설정 창 (공통 요소) | 없음 |

**그림**
- `bg_title`: 배경
- `title_logo`: 게임 이름 로고
- `title_start`: 시작 글자 그림
- `title_exit`: 종료 글자 그림

## 2. 로비
**목적**: 주와 주 사이의 거점. 장보기로 가기, 도감·칭호·냉장고 보기.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 게임 시작 | 장보기 화면으로 간다 | Enter |
| 도감 | 도감 화면을 연다 | D |
| 칭호 | 칭호 화면을 연다 | T |
| 냉장고 | 냉장고(보관 재료) 화면을 연다 | 없음 |
| 설정 | 설정 창 (공통) | 없음 |
| 타이틀 | 타이틀로 간다 (공통) | 없음 |

**정보 표시**
- 현재 주차
- 현재 예산(돈)
- 새 칭호 획득 알림 (주가 끝난 뒤 처음 들어올 때)

**그림**
- `lobby_bg`: 배경
- `lobby_desk`: 책상 그림
- `lobby_day`: 주차(날짜) 표시 그림
- `lobby_money`: 금액 표시 그림
- `lobby_character`: 캐릭터 (칭호 버튼 역할 포함)
- `lobby_titletag`: 칭호 표시 그림
- `lobby_fridge`: 냉장고 버튼 그림
- `lobby_dex`: 도감 버튼 그림
- `lobby_start`: 게임 시작 버튼 그림

## 3. 장보기 (상점)
**목적**: 예산 안에서 이번 주에 쓸 재료를 고른다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 재료 줄 (재료마다) | 재료 이름, 가격, 유통기한(일수), 적합 방식을 보여 준다 | 없음 |
| 빼기 (−) | 장바구니에서 그 재료 한 개를 뺀다 | 없음 |
| 더하기 (+) | 장바구니에 그 재료 한 개를 넣는다 | 없음 |
| 구매 확정 | 장바구니를 확정하고 하루 선택으로 간다. 최소 개수를 채워야 활성화된다 | Enter |
| 최소 개수 안내 | 아직 최소 개수가 안 찼을 때 필요한 개수를 보여 준다 (구매 확정 자리에 보임) | 없음 |
| 로비 | 로비로 간다 (확인 창) | 없음 |

**정보 표시**
- 현재 예산, 장바구니 합계 금액
- 장바구니에 담긴 재료와 개수
- 재료별 유통기한

**그림**
- `bg_shop`: 배경
- `shop_basket_back`, `shop_basket_front`: 장바구니 (뒤, 앞). 없으면 `shop_basket` 한 장
- `<재료>_shop`: 재료 아이콘 (재료 6종: egg, tofu, onion, potato, pork, kimchi. 새우는 해금 후)

## 4. 하루 선택
**목적**: 오늘 먹을 재료와 조리 방식을 고른다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 재료 칸 (재료마다) | 오늘 쓸 재료로 고르거나 뺀다 (끌어다 놓기도 가능) | 없음 |
| 조리 방식 버튼 (4개) | 굽기, 볶기, 끓이기, 튀기기 중 하나를 고른다. 튀기기는 해금 후 | 각각 Q, W, E, R |
| 엄마 전언 | 추천 레시피 목록을 연다 (모달) | M |
| 도감 | 도감을 연다 | 없음 |
| 조리 시작 | 선택한 재료와 방식으로 조리 화면을 연다. 재료와 방식이 모두 있어야 활성화된다 | Enter |
| 로비 | 로비로 간다 (확인 창) | 없음 |

**정보 표시**
- 오늘 날짜 (일차), 주차
- 남은 재료와 유통기한
- 선택한 재료, 선택한 방식

**그림**
- `icon_pan`(굽기), `icon_wok`(볶기), `icon_pot`(끓이기), `icon_fry`(튀기기): 방식 아이콘
- `<재료>_shop`: 재료 아이콘
- 식탁보와 도마: `Kitchen/tablecloth`, `Kitchen/cutting_board` (선택, 없으면 단색)

## 5. 조리 (방식별 3개 화면)
조리 화면은 방식마다 따로 본다. 공통 요소는 세 화면에 모두 들어간다.

### 5-0. 세 화면 공통
**목적**: 재료를 익히고 알맞을 때 꺼낸다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 불 세기 (3단계: 약불, 중불, 강불) | 불 세기를 바꾼다. 현재 단계가 드러나야 한다 | 없음 |
| 재료 넣기 | 도마의 재료를 팬·웍·냄비에 넣는다 | Z, X, C, V, B, N (재료 순서) |
| 재료 꺼내기 | 익은 재료를 꺼내 접시에 올린다 | Z, X, C, V, B, N (같은 키) |
| 모두 꺼내기 | 팬의 재료를 모두 꺼낸다 | Enter |
| 로비 버튼 | 확인 창을 거쳐 로비로 간다 | 없음 |

**정보 표시**
- 남은 시간 (타이머)
- 조리 상태 (익는 중 등)
- 재료마다 익힘 정도 (게이지: 날것, 덜 익음, 알맞음, 과함, 탄 것 5단계)
- 엄마의 한마디 (재료와 방식에 따른 말풍선)

**그림 (공통)**
- 재료 5단계 그림: `<재료>_raw`, `_under`, `_good`, `_over`, `_burnt` (재료 6종 × 5장)
- 타이머: `cook_timer`, 말풍선: `cook_tip`
- 가스 밸브 손잡이: `Kitchen/knob` (선택)

### 5-1. 굽기 화면
**목적**: 익힘 30~40 사이에 뒤집고, 알맞을 때 꺼낸다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 뒤집기 버튼 | 익힘 30~40 사이에 누른다. 뒤집지 않으면 익힘 구간이 좁아진다. 글자는 상태에 따라 바뀐다 | Space |
| 뒤집기 상태 안내 | 뒤집기 가능 시점, 뒤집었는지 여부를 보여 준다 | 없음 |
| 굽기 조작 안내 | "뒤집기 타이밍"을 알려 준다 | 없음 |

**그림**
- 배경: `bg_cook_grill`
- 팬: `cook_pan`
- 뒤집개: `cook_spatula`
- 뒤집기 버튼 바탕: `cook_flip_btn`

### 5-2. 볶기 화면
**목적**: 계속 저어 눌어붙지 않게 하고, 알맞을 때 꺼낸다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 젓기 칸 | 누르는 동안 젓는다. 연타한다. 멈추면 눌어붙는다 | Space (연타) 또는 칸 누르기 |
| 젓기 상태 안내 | 젓는 중인지, 멈춘 시간이 얼마인지 보여 준다 | 없음 |
| 볶기 조작 안내 | "계속 저어라"를 알려 준다 | 없음 |

**그림**
- 배경: `bg_cook_wok`
- 웍: `cook_wok`
- 주걱: `cook_spoon`

### 5-3. 끓이기 화면
**목적**: 거품이 올라오면 뚜껑으로 가라앉히고, 알맞을 때 꺼낸다.

| 요소 | 기능 | 키 |
| --- | --- | --- |
| 뚜껑 칸 | 누르고 있으면 뚜껑을 덮는다. 거품이 떠 있는 동안 0.5초씩 눌러 가라앉힌다 | Space (누르기) 또는 칸 누르기 |
| 거품 표시 | 거품이 올라왔는지, 가라앉혀야 하는지 보여 준다 | 없음 |
| 끓이기 조작 안내 | "거품이 올라오면 뚜껑"을 알려 준다 | 없음 |

**그림**
- 배경: `bg_cook_pot`
- 냄비: `cook_pot`
- 뚜껑: `cook_pot_lid`

> 튀기기 화면(`bg_cook_fry`)은 해금 후 따로 적는다.

## 14. 확인 창 (모달)
아래 상황에서 뜬다. 공통으로 **계속하기**(닫기)와 **진행하기** 두 버튼이 있다.

| 창 | 정보 | 버튼 | 키 |
| --- | --- | --- | --- |
| 로비로 갈까요? | 이번 주 진행이 취소되고, 쓴 돈과 재료는 되돌아오지 않는다. 조리 중이면 그 재료도 사라진다 | 계속 하기 / 로비로 가기 | Esc / 없음 |
| 엄마의 전언 (추천 레시피) | 추천 레시피 목록 | 이걸로 할래 [1~] | 숫자 키 |
