## 개요
[17 확정사항](17확정사항_로비칭호튀김.md)의 칭호와 튀김 해금을 구현한 내용이다. 확정 규칙은 17번을 따르고, 이 문서는 **어떻게 구현했는지와 17번에 없어서 정한 값**만 적는다. 수치는 모두 초안이다.

## 구현 위치
| 파일 | 내용 |
|---|---|
| `Titles.cs` | 칭호 8개 정의, 판정, 대표 칭호, 저장(`titles.json`). 해금 여부(`Titles.FryUnlocked`)도 여기서 읽는다 |
| `Data.cs` | 새우 재료, `Data.Unlocked`, `Data.Active`(쓸 수 있는 재료), `Data.ActiveMethods`(쓸 수 있는 방식), 튀기기 수치 |
| `Cook.cs` | 튀기기 고유 조작(기름 온도) |
| `GameFlow.cs` | 장보기·하루 선택·도감이 `Data.Active`/`ActiveMethods`를 읽는다. 결산에서 칭호 판정과 알림, 칭호 목록 화면 |

## 칭호 (17번 그대로)
| 칭호 | 조건 | 보상 |
|---|---|---|
| 집밥 입문 | 도감 5종 | 없음 |
| 자취 생존자 | 도감 10종 | **튀김 해금** (새우 + 튀기기) |
| 동네 밥집 사장 | 도감 20종 | 없음 |
| 한식 달인 | 도감 35종 | 없음 |
| 굽기 장인 / 볶기 장인 / 끓이기 장인 | 해당 방식 5종 | 없음 |
| 튀김 명인 | 튀김 3종 | 없음 |

- 한 판(7끼니)에서 서로 다른 요리가 7개 안팎이라, 10종은 1~2주 안에 닿는다. 1주차 안에 해금하고 싶으면 `Titles.cs`의 자취 생존자 수치(10)를 5 안팎으로 낮추면 된다(팀 확정 필요).
- 판정은 한 주가 끝나는 결산 화면(`ShowResult`)에서 한다. 굶어서 끝나는 결산(`ShowFail`)에서도 판정한다. 새로 얻은 칭호가 있으면 팝업으로 알리고, "자취 생존자"를 얻으면 튀김 해금도 함께 알린다.
- 칭호는 `titles.json`(대표 칭호 포함)에, 도감은 `dex.json`에 저장한다. 해금 상태는 "자취 생존자" 보유 여부로 정해서 따로 저장하지 않는다.
- 대표 칭호는 처음 얻은 칭호가 자동으로 되고, 칭호 목록([T])에서 바꾼다. 칭호 목록은 로비에서만 열 수 있다 (결산 화면에는 칭호 버튼과 대표 칭호를 두지 않는다).
- 버프는 없다(영구 버프는 프로토타입 이후).

## 튀김 해금
- **새우**: 2,000원, 유통기한 2일, 기본 점수 80, 속도 ×1.1, 튀김에만 맞는다. 해금 전에는 상점·도감·재료 칩에 나오지 않는다. 해금 후 다음 장보기부터 나온다.
- **튀기기**: 속도 5(중불 기준), 적정 구간 65~85. 해금 전에는 방식 선택지(Q/W/E/R)에 나오지 않는다.
- **적합 재료**: 새우, 감자, 두부, 양파, 돼지고기. 달걀·김치는 궁합 ×0.6.
- **고유 조작(기름 온도 유지, 초안)**: 팬에 재료가 있는 채로 약불에 누적 1.5초 이상 두면 기름이 식어 눅눅해져 만족도 ×0.7 (`OilGrace`, `SoggyCoef`). 약불이면 화면에 경고가 뜬다. 17번에 "조작 세부는 상의"로 남아 있어 가장 단순한 형태로 만들었다.
- **도감**: 해금 전에는 튀김 칸이 없고, 해금되면 새우와 튀기기 칸이 생긴다. 이미 만든 요리는 항상 보인다.
- **튀김 메뉴 이름**: 새우튀김, 새우감자튀김, 새우양파튀김, 새우두부튀김, 감자튀김, 두부튀김, 양파튀김, 돈가스, 감자돈가스, 채소두부튀김, 감자양파튀김. 엄마의 레시피(`Recipes.Steps`)에 튀김 요령 한 줄이 있다.
- **그림**: 새우 그림 6장(`shrimp_shop.png`, `shrimp_raw`~`shrimp_burnt`)은 다른 재료와 같은 크기·스타일로 코드로 그린 임시 그림이다. 아트 담당이 같은 파일 이름으로 바꿔 넣으면 된다. 튀기기 배경 `bg_cook_fry.png`는 없어서 웍 그림을 쓴다([13 아트 가이드](13아트가이드.md)).

## 아직 정하지 않은 것
- 튀김 고유 조작의 최종 모양 (혁진님과 상의로 남아 있음)
- 칭호 수치와 튀김 수치의 밸런스. 도감 10종이 1~2주 안에 닿는지 플레이로 본다.
- 칭호 이름과 알림 연출 (디자인 단계에서)
- 로비가 생기면 해금 연출 위치를 결산 팝업에서 로비로 옮긴다.
