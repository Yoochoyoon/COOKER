## 개요
[08번](08보상체계와피드백반영.md)에서 정한 칭호 시스템과 조리 방식 해금을 프로토타입 규모로 구현한 것이다. 수치는 모두 초안이며, 직접 플레이하며 `Data.cs`(`Balance`)와 `Titles.cs`에서 고친다.

## 조리 방식 해금: 튀기기
- **튀기기**는 새 방식이고 **2주차부터** 열린다 (`Balance.FryUnlockWeek`). 1주차에는 하루 선택 화면에 "튀기기 (2주차 해금)"으로 잠겨 보이고, 2주차 첫날에 "새로 열렸다: 튀기기!"가 뜬다.
- 해금은 판(런) 안의 주차로 정한다. 새 판을 시작하면 다시 1주차부터라 다시 잠긴다. 엄마의 전언도 열린 방식으로만 추천한다.
- **튀김 메뉴**: 감자튀김, 두부튀김, 양파튀김, 돈가스(돼지고기), 감자돈가스, 채소두부튀김, 감자양파튀김. 새 재료는 없고 기존 재료를 쓴다.
- 튀기기에 맞는 재료: 감자, 두부, 양파, 돼지고기(달걀·김치는 맞지 않아 ×0.6).
- 수치: 속도 5, 적정 구간 62~76 (굽기 다음으로 빠르고 구간이 좁다).
- **고유 조작 (초안)**: 팬에 재료가 있는 동안 6초마다 기름이 튄다. 이때 [건지기!](Space)를 1.5초 안에 누르지 않으면 눅눅해져 만족도 ×0.8 (`SplashInterval`, `SplashGrace`, `SplashCoef`). 다른 방식과 같은 "안 하면 불이익" 구조다.
- 조리 배경은 전용 그림이 없어 웍 그림(`bg_cook_wok`)을 임시로 쓴다. `Assets/Resources/Art/bg_cook_fry.png`를 넣으면 자동으로 그것을 쓴다.

## 칭호 (8개)
- **획득**: 도감에 쌓인 요리로 조건을 채우면 얻는다. 결과는 `titles.json`에 저장된다(도감도 `dex.json`에 저장).
- **장착**: 하나만 장착한다. 장착은 타이틀과 주 결산 화면([T])에서만 바꾼다. 장착하지 않으면 버프가 없다.
- **난이도 랭크** D·C·B·A: 방식 점수(끓이기 0, 굽기·볶기 1, 튀기기 2) + (재료 수 − 1) + (1,500원 이상 재료가 있으면 1)에서 1을 뺀 값. 랭크 A는 튀기기에 비싼 재료를 2개 섞을 때만 나온다.
- **대표 레시피**: `Recipe.cs`의 요리 이름 표에 이름이 있는 조합이다.

| 칭호 | 종류 | 조건 | 버프 |
|---|---|---|---|
| 구이 장인 | 기본 | 굽기 대표 레시피 3종 | 굽기 적정 구간 ±4 |
| 볶음 장인 | 기본 | 볶기 대표 레시피 3종 | 볶기 적정 구간 ±4 |
| 국물 장인 | 기본 | 끓이기 대표 레시피 3종 | 끓이기 적정 구간 ±4 |
| 튀김 장인 | 기본 | 튀기기 대표 레시피 3종 | 튀기기 적정 구간 ±4 |
| 재료 탐험가 | 기본 | 재료 6종을 모두 요리에 써 보기 | 모든 재료 유통기한 +2일 |
| 미식가 | 기본 | 랭크 B 이상 요리 3개 | 모든 요리 기본 점수 +5 |
| 자취 고수 | 상위 | 기본 칭호 3개 + 랭크 A 요리 1개 | 모든 방식 구간 ±3, 기본 점수 +3 |
| 요리 달인 | 상위 | 기본 칭호 6개 모두 | 모든 방식 구간 ±5, 기본 점수 +5, 유통기한 +2일 |

- 08번의 6개 카테고리 중 삶기·찌기는 만들지 않아, 기본 칭호는 방식 4개 + 재료·랭크 2개로 구성했다.
- 08번의 버프 네 가지 중 알러지 해소는 프로토타입에서 뺐다.
- 칭호를 얻으면 식사 화면에 "칭호 획득!"이 뜬다.

## 아직 정하지 않은 것
- 튀기기 해금 주차(2주차)와 칭호 수치(±4, +5 등)의 밸런스. 만족도가 쉽게 100에 닿거나 너무 어렵지 않은지 플레이로 본다.
- 칭호 버프가 주마다 초기화되는지(지금은 저장되어 새 판에도 유지된다).
- 튀기기의 고유 조작을 이대로 둘지(08번 초안은 "기름에서 건지는 순간 맞추기"). 
- 방식 해금을 칭호나 도감 달성으로 바꿀지 (지금은 주차).
