# 29 간 맞추기 명세

조리가 끝난 뒤 간을 골라 맛을 정하는 기능의 구현 명세다. 담당은 [유초윤](#9-담당) 님이며, 화면 배치와 연출도 유초윤 님이 맡는다.

> **미확정** 표시 항목은 팀에서 확정한 뒤 이 문서를 고친다.

## 1. 목적

- 조리가 끝나면 간을 한 번 골라, 맛의 마지막 결정을 플레이어가 하게 한다.
- 모든 조리 방식(굽기, 볶기, 끓이기)에 같은 구조를 쓴다.
- 선택은 시간 제한 없이 하되, 전체 조리 시간 감점은 따로 적용한다(`docs/30`).

## 2. 흐름

1. 조리 완료 버튼을 누른다.
2. 조리 화면 위에 어두운 막을 씌운다. 뒤의 조리 화면은 보이지만 조작은 막는다.
3. 가운데 패널에 간 선택지 네 개를 2×2로 크게 띄운다.
4. 플레이어가 하나를 고르면 패널이 닫히고, 맛 보정이 적용된다.
5. 결과(꺼내기 단계, 전체 익힘, 간 결과)를 합쳐 결과 화면으로 넘어간다.

- 한 번 고르면 되돌릴 수 없다.
- 키 입력으로만 고른다. 마우스 클릭도 허용한다.

## 3. 선택지

방식마다 네 개를 둔다. 정답은 방식마다 하나씩 둔다.

| 방식 | 선택지 (4개) | 정답 (제안) |
| --- | --- | --- |
| 굽기 | 소금, 후추, 간장, 설탕 | 소금 |
| 볶기 | 간장, 설탕, 소금, 고춧가루 | 간장 |
| 끓이기 | 국간장, 고춧가루, 소금, 후추 | 국간장 (두부 또는 달걀이 들어간 경우). 김치가 들어간 경우 고춧가루 |

**미확정:**
- 방식별 선택지 네 개. 목업에서는 네 방식 공통으로 소금, 간장, 설탕, 고춧가루를 썼다.
- 정답 규칙. 끓이기처럼 재료에 따라 정답이 바뀌는 경우의 조건.

## 4. 키 (제안)

| 선택지 | 키 |
| --- | --- |
| 첫 번째 | Q |
| 두 번째 | W |
| 세 번째 | E |
| 네 번째 | R |

- 키는 버튼 글자 안에 `[키]`로 적는다. 예: `소금 [Q]`.
- 쓰는 키가 기존 조작(Space, Z X C V B N, 1~3)과 겹치지 않는지 확인한다.

**미확정:** 키 네 개. 충돌 확인 후 확정한다.

## 5. 맛 보정

| 결과 | 보정 |
| --- | --- |
| 정답 | 전체 익힘 값의 맛 점수에 가산 |
| 오답 | 맛 점수에서 감산 |

- 보정 값은 `BalanceData`에 둔다.
- 맛 점수는 만족도 계산에 넘긴다. 실패(굶음)를 바로 만들지는 않는다.

**미확정:** 가산과 감산의 크기. 제안은 정답 +10, 오답 -10 (0~100 기준)이다.

## 6. 선택하지 않은 경우

- 시간 제한은 두지 않는다.
- 결과 화면으로 넘어가려면 반드시 하나를 골라야 한다.
- 실수로 닫는 것을 막기 위해 닫기 버튼은 두지 않는다.

## 7. 연출 (유초윤 님 담당)

- 어두운 막은 뒤 화면을 가린다. 흐림 효과 대신 어두운 막을 쓴다.
- 패널이 나타나는 짧은 연출을 넣을 수 있다. 연출 길이는 0.3초 이내로 한다.
- 선택 직후 선택지 버튼의 색을 바꿔 고른 것을 보여 준다.

## 8. 코드 연결 (제안)

새 파일 `Cook.Season.cs`에 partial class로 둔다. 기존 파일에는 호출만 추가한다.

- **속성:** 방식별 선택지, 방식별 정답, 고른 선택지, 선택 완료 여부.
- **메서드:** 조리 완료 시 간 고르기 시작, 선택 판정, 맛 보정 반환.

`Cook.cs`의 조리 완료 처리에서 간 고르기를 시작한다. 패널 그리기와 키 입력 연결은 유초윤 님이 맡는다.

## 9. 담당

- **유초윤:** `Cook.Season.cs`(새 파일), 선택지와 정답, 맛 보정, 패널 화면, 연출, 키 입력, `BalanceData` 수치, `docs/09` 기록.

## 10. 테스트

- 네 방식 모두에서 네 선택지가 나오는지 확인한다.
- 정답을 고르면 맛 보정이 가산되는지 확인한다.
- 오답을 고르면 맛 보정이 감산되는지 확인한다.
- 선택하기 전에는 결과 화면으로 넘어가지 않는지 확인한다.
- 키 네 개가 기존 조작과 겹치지 않는지 확인한다.
- 간 고르기 중 뒤 조리 화면의 조작이 막히는지 확인한다.
- 빌드 전에 인터넷을 끊고 한 판을 끝까지 돌린다.

## 11. 확정이 필요한 것

1. **방식별 선택지와 정답:** 네 방식의 선택지 네 개와 정답. 끓이기의 정답 규칙.
2. **키 네 개:** Q, W, E, R이 기존 조작과 겹치지 않는지.
3. **보정 값:** 정답과 오답의 가산, 감산 크기.
