# COOKER 한 장 요약 (2026-11-04 기준)

## 한 줄 소개
냉장고가 빈 한 주(7일) 동안, 정해진 예산으로 장을 보고 매 끼니를 직접 요리해 굶지 않고 버티는 한국 가정식 요리 생존 게임. (Unity 6, 마우스·키보드)

## 한 판의 흐름
1. **타이틀** → 시작
2. **장보기 (주 1회)**: 예산 10,000원으로 재료 6종(달걀·두부·양파·감자·돼지고기·김치)을 사서 장바구니에 담는다. 재료마다 가격과 유통기한(3~7일)이 다르다.
3. **하루 반복 (7일)**: 오늘 쓸 재료 1~2개와 조리 방식을 고른다 → 조리 → 식사 → 결산. 엄마의 전화·추천 레시피가 힌트를 준다.
4. **종료**: 한 끼라도 날것이나 탄 요리로 실패하면 굶음으로 끝난다(첫날 제외). 버틴 주차가 점수. 매주 재료값이 8% 오른다.

## 조리 (게임의 핵심 손맛)
| 방식 | 적정 구간 | 해야 할 것 | 안 하면 |
|---|---|---|---|
| 굽기 | 60~75 (좁음) | 뒤집기 버튼이 뜨면 누르기 | 구간이 좁아져 타기 쉽다 |
| 볶기 | 55~80 | 계속 저어 주기(Space 연타) | 눌어붙어 만족도 ×0.6 |
| 끓이기 | 50~90 (넓음) | 거품이 오르면 뚜껑 누르기 | 끓어넘쳐 만족도 ×0.7 |

- 불은 밸브 손잡이로 조절(약·중·강). 재료는 도마에서 팬으로 끌어다 놓거나 클릭.
- **익힘 게이지**(하양→노랑→주황→빨강)가 주황일 때 꺼내는 게 정답. 재료 그림도 5단계(날것~탄 것)로 바뀐다.
- 만족도 = 재료 기본 점수 × 방식 궁합 × 익힘 계수. 두 재료를 모두 성공시키면 +10%.

## AI 요소
- **요리 이름**: 만든 요리에 AI가 실제 음식 이름을 붙인다.
- **요리 그림**: 성공한 요리만 AI가 귀여운 카툰풍으로 그려 도감에 넣는다(망친 요리는 생성 안 함). 에디터 테스트는 무료 서비스, 빌드는 유료 모델.
- 게임 숫자(점수·가격·난이도)에는 AI를 쓰지 않는다.
