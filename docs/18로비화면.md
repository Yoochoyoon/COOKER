# 로비 화면 (UI 디자인용)

로비는 타이틀 다음, 그리고 **한 주 정산이 끝날 때마다** 돌아오는 거점 화면이다. 현재 구현(`Lobby.cs`)은 구성만 있고 디자인은 없다. 이 문서는 최종 UI를 그리기 위한 기준이다. 확정 사항의 원문은 [17](17확정사항_로비칭호튀김.md).

현재 모습: [화면스샷/02_로비.png](../화면스샷/02_로비.png), 칭호 획득 팝업: [12_로비_칭호획득.png](../화면스샷/12_로비_칭호획득.png), 칭호 목록: [09_칭호목록.png](../화면스샷/09_칭호목록.png)

## 화면 흐름
```
타이틀 → 로비 → 장보기 → [ 7일 → 일주일 정산 ] → 로비 → 장보기 → ...
```
- 정산이 끝나면 로비로 돌아온다. 이때 **새로 얻은 칭호가 있으면 로비 위에 칭호 획득 팝업**이 먼저 뜨고, 닫으면 일반 로비가 된다.
- 굶어서 실패하면 "다시 하기" → 타이틀 → 새 판 시작 → 로비.
- [게임 시작]은 장보기로 이동한다.

## 캔버스
- **1920 × 1080 (16:9)**, 배경은 화면 전체를 덮는 한 장. 글자는 그림에 굽지 않고 코드로 넣는다 (일차·금액·칭호는 계속 바뀐다).
- 아래 좌표는 화면 비율(0~1, 왼쪽 아래가 0,0)이다. 픽셀은 가로 ×1920, 세로 ×1080.

## 요소 배치 (현재 구현 기준)
| 요소 | 위치 (x0,y0 ~ x1,y1) | 내용 | 상태 |
|---|---|---|---|
| 제목 "로비" | 0.03,0.86 ~ 0.50,0.98 | 화면 이름. 디자인에서 로고나 간판으로 대체해도 됨 | 구현됨 |
| 현재 일차 카드 | 0.05,0.62 ~ 0.47,0.82 | "N주차 N일 차 (총 N일 차)" | 구현됨 |
| 보유 금액 카드 | 0.53,0.62 ~ 0.95,0.82 | "N,NNN원" | 구현됨 |
| 주인공 캐릭터 | 0.05,0.24 ~ 0.47,0.57 | 캐릭터 그림 + **머리 위 대표 칭호**. 누르면 칭호 목록 | 자리만 (유초윤, 후순위) |
| 냉장고 버튼 | 0.53,0.24 ~ 0.95,0.57 | 이미지 버튼. 누르면 **현재 가진 재료** 표시 | 자리만 (유초윤, 후순위) |
| 도감 버튼 | 0.05,0.05 ~ 0.24,0.19 | 도감 화면 열기. 키 `D` | 구현됨 |
| 칭호 버튼 | 0.27,0.05 ~ 0.46,0.19 | 칭호 목록 열기. 키 `T` (캐릭터가 생기기 전 임시 진입점) | 구현됨 |
| 게임 시작 버튼 | 0.55,0.05 ~ 0.95,0.19 | 장보기로 이동. 키 `Enter` / `Space` | 구현됨 |

위치는 디자인에 맞춰 바꿔도 된다. 바꿀 때는 `Lobby.cs`의 좌표만 고치면 된다.

## 캐릭터와 칭호
- 캐릭터 머리 위에 **대표 칭호** 한 줄을 띄운다. 없으면 "없음" 또는 비워 둔다.
- 캐릭터를 누르면 칭호 목록이 열린다: 전체 8개, 잠긴 칭호의 해금 조건과 힌트, 대표 칭호 변경.
- 칭호 목록은 로비·타이틀·주 결산 화면에서 대표 칭호를 바꿀 수 있다.

| 칭호 | 조건 |
|---|---|
| 집밥 입문 | 도감 5종 |
| 자취 생존자 | 도감 10종 (튀김 해금) |
| 동네 밥집 사장 | 도감 20종 |
| 한식 달인 | 도감 35종 |
| 굽기 / 볶기 / 끓이기 장인 | 해당 방식 5종 |
| 튀김 명인 | 튀김 3종 |

## 냉장고
- 누르면 지금 가진 재료 목록 창이 뜬다: 재료 이름, 개수, **남은 유통기한**. 로비는 장보기 직전이라 주 정산 때 남은 재료를 확인하는 용도다.
- 아직 확정되지 않은 기능이라 후순위다. 그림은 닫힌 상태 / 눌렀을 때(열린 상태) 두 장이 있으면 좋다.

## 디자인할 때 알아둘 것
- 로비에 올 때마다 보이므로 **한 주를 끝낸 뒤의 안도감** 같은 분위기가 어울린다.
- 가장 눈에 띄는 것은 [게임 시작] 버튼이어야 한다.
- 일차와 금액은 큰 글자로 한눈에 읽혀야 한다 (지금 글자 크기는 일차·금액 52, 라벨 32, 버튼 40~48).
- 칭호 획득 팝업은 지금 단순한 창이다. 연출을 넣고 싶으면 별도로 그린다 (칭호 이름은 1~2줄).
- 튀김이 해금되면 새우가 상점에 나오고 튀김 조리가 열린다. 로비에서 이를 알리는 연출을 넣을 수 있다.

## 코드 쪽 메모
- 화면 내용은 `Assets/Scripts/Lobby.cs`, 흐름은 `GameFlow.cs`의 `ShowLobby`가 맡는다.
- 단축키(`Enter`/`Space` 시작, `D` 도감, `T` 칭호)는 GameFlow의 공통 메뉴 키 처리에서 받는다.
- 칭호 획득 팝업은 `ShowLobby`가 로비를 그린 직후 띄운다.
